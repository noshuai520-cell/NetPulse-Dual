## 🎯 為什麼需要 NetPulse Dual？

許多寬頻業者針對主流測速網站設有「專屬加速白名單」，導致平常測速看似滿速，但一到晚間尖峰看 4K 影片、打海外遊戲或視訊會議就瘋狂轉圈爆 Ping。

**NetPulse Dual v2.1** 採用 **「雙獨立引擎交叉驗證」** ＋ **「內外網拓撲與海纜路由探針」**，免安裝、單一綠色執行檔直接運作，幫你一秒揪出真正病灶！

## ✨ v2.1 核心功能亮點

### 1. 🧭 內網路由拓撲掃描（一秒分清內網或外網問題）
* 開啟程式自動偵測 **本機網卡協商速率 ➔ 家用數據機/路由器第一跳延遲 ➔ 外網出口 IP 與 NAT 架構**，立刻判斷卡頓是家裡 Wi-Fi / 網路線老化，還是外部電信機房異常。

### 2. ⚡ 雙獨立核心交叉抓包（專抓流量整形 / 偷限速）
* **【引擎 A】Ookla CLI 官方核心**：測試底層物理極限頻寬、閒置延遲、抖動（Jitter）、掉包率，並具備 **下載（青藍）➔ 上傳（翡翠綠）雙階段即時圓弧與波形曲線動畫**。
* **【引擎 B】LibreSpeed 開源無白名單核心**：緊接著進行無白名單純 HTTP 實測，兩者落差過大立即觸發「疑似 ISP 流量整形」警告。

### 3. 🌏 海外海纜路由延遲偵測 *(v2.1 新增)*
* 直接實測連線至 **日本東京（JP）** 與 **美國西岸（US）** 骨幹節點的 TCP 握手延遲，快速抓出台灣寬頻常見的「海纜斷裂繞路（連台灣很快、連海外卻大爆 Ping）」。

### 4. 🚦 黃金 3 場景紅綠燈體感評估 *(v2.1 新增)*
* 綜合無白名單吞吐量、抖動與雙向 Bufferbloat 數據，自動轉化為一般人秒懂的三大日常情境判定：
  * **🎬 4K 影音串流**：評估高畫質串流是否順暢滿畫質或易轉圈。
  * **🎮 線上競技遊戲**：嚴格檢驗閒置延遲與滿載爆 Ping 瞬移風險。
  * **💼 視訊 / 大檔上傳**：檢測上傳頻寬與上傳緩衝塞車狀況。

### 5. 🛡️ 24H 省流哨兵監控 ＋ CSV 客訴鐵證報表
* **平時零干擾**：每 30 秒僅發送極輕量骨幹心跳探針（完全不佔頻寬、不影響追劇打遊戲）。
* **異常自動抓包存證**：一旦偵測到延遲飆升或瞬斷，自動啟動雙引擎全速測速並寫入 **CSV 完整工程診斷報表**，提供給客服最有力證據。

## 📥 快速下載與使用方式

1. 前往右側 **[Releases 頁面](https://github.com)** 下載最新版的 **`NetPulseDual_v2.1.exe`**。
2. **完全免安裝**，雙擊執行檔即可啟動（內建測速核心，無需額外安裝環境）。
3. 選擇家中的「申裝頻寬方案」與「容許誤差（PPPoE 建議選 8%）」，點擊 **「▶ 單次雙引擎診斷」** 或 **「🛡️ 啟動哨兵監控」** 即可開始！

---

## 🛠️ 自行從原始碼編譯 (Build from Source)

若你想自行檢視原始碼或編譯，只需準備 Windows 內建的 .NET Framework 4.x 環境：
1. 下載本倉庫的 `Program.cs` 與 `build.bat`。
2. 將官方 `speedtest.exe`（Ookla CLI）與 `librespeed-cli.exe` 放入同一資料夾。
3. 雙擊執行 **`build.bat`**，即可自動將雙引擎封裝編譯為單一獨立執行檔。
