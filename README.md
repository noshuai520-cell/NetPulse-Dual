# ⚡ 網速哨兵 Pro (NetWatchdog Pro)

專為台灣光纖寬頻環境設計的**全自動斷線與掉速監控工具**。內嵌 Ookla 官方 Speedtest CLI 測速核心，免安裝、單一執行檔隨處可用，能精準捕捉網路瞬斷與尖峰掉速，並自動產出帶有官方認證網址的 CSV 報表，作為向電信商報修的客觀依據。

---

## ✨ 核心特色

* **📦 單一綠色執行檔**：已將官方 Speedtest 測速核心內嵌封裝，無需額外安裝環境或手動建置資料夾，雙擊即用。
* **🛡️ 智慧雙層巡檢機制**：
  * **日常輕量巡檢**：每 30 秒對中華電信骨幹 DNS (`168.95.1.1`) 進行低負載 TCP Ping 探測，不佔用日常頻寬。
  * **異常即時抓包**：當偵測到延遲飆高（> 50ms）、斷線或每 15 分鐘定期巡檢時，自動啟動完整 Speedtest 實測並記錄。
* **🇹🇼 內建台灣主流頻寬方案**：支援 `100M/40M`、`100M/100M`、`300M/300M`、`500M/250M`、`500M/500M`、`1G/600M`、`1G/1G`、`2G/1G`，並提供 `3% ~ 20%` 多段容許誤差（含 PPPoE 標頭損耗建議值）。
* **📊 自動匯出舉證報表**：狀態發生異動（正常 → 掉速、斷線、恢復正常）時，自動將時間、上下傳速率、延遲與 **Speedtest 官方認證網址** 寫入同目錄的 `.csv` 報表中（內建檔案鎖定防呆機制，即使用 Excel 開著報表也能持續寫入備援檔）。

---

## 🚀 快速開始

### 方法一：直接下載執行檔（推薦一般使用者）
1. 點擊本頁面右側的 **[Releases](../../releases)** 區塊。
2. 下載最新版本的 **`網速哨兵 Pro.exe`**。
3. 直接雙擊執行，選擇你的申請方案與容許誤差，點擊 **「▶ 啟動監控」** 即可。

### 方法二：透過 PowerShell 腳本自行編譯打包（開發者）
1. 下載本倉庫中的 `Build-NetWatchdog.ps1`。
2. 確保本機或暫存資料夾具備官方 `speedtest.exe`（Windows CLI 版本）。
3. 以 PowerShell 執行腳本，系統將自動調用 .NET C# 編譯器，在桌面生成獨立的 `網速哨兵 Pro.exe`。
